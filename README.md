# 🎓 EduTube

EduTube is a responsive educational video learning platform built with HTML, CSS, Tailwind CSS, and JavaScript.

## 🚀 Live Demo

https://elamathi-tech.github.io/edutube/

## ✨ Features

- Responsive Home Page
- Explore Courses
- Video Watch Page
- Learning Path
- Quiz Page
- Contact & Feedback Form
- Dark Mode
- Mobile Navigation
- GitHub Pages Deployment

## 🛠 Tech Stack

- HTML5
- CSS3
- Tailwind CSS
- JavaScript
